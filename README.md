# 공정·저장탱크 SPC 관리대장

공정 측정값과 품질을 관리하는 프로젝트입니다.

Node.js 22 이상에서 외부 npm 의존성 없이 실행하는 한국어 SPC 웹 앱입니다.

```sh
cd /workspace/smchoi
npm start
```

기본 포트는 3000이며 `PORT`로 바꿀 수 있습니다. 서버는 `0.0.0.0`에 바인딩됩니다. 설치 및 빌드 과정은 필요하지 않습니다. 기존 체크아웃을 사용하고 별도 Git worktree를 만들지 않습니다. 새 실행 환경에서는 서버를 다시 시작하세요. HTTP `/` 및 `/workbook.json`의 200 응답으로 준비 상태를 확인합니다.

## 관리 구조

- 공정 및 저장탱크 TK-501~506, A·B·C별 독립 기록, 추가 대상 등록
- 분석 항목별 기록, 단위·장비·선택적 상한/하한 규격 설정, 추가 항목 등록
- 여러 대상 선택 및 이름 있는 그룹 저장·삭제. 기본 그룹: 공정 + 저장탱크 A + C
- 선택 항목과 기간에 대한 라인별 평균, 규격 이탈, Cpk 및 I-MR 관리도
- 입력 시 대상·항목 지정, 날짜와 당일 순번 기록, 개별 기록 삭제
- 조회 결과 CSV 및 전체 JSON 백업·복원 (복원 시 현재 데이터를 교체하므로 확인 필요)

여러 라인을 그룹으로 조회해도 서로 다른 공정 데이터를 섞어 관리한계를 추정하지 않습니다. 개별값·이동범위 관리도 모두 선택 그룹 내 모든 라인을 색상과 범례로 구분해 동시에 표시합니다. 날짜를 공통 가로축으로 사용하고 당일 순번에 따라 점을 배치하며 라인별 관리한계를 점선으로 표시합니다. 조회 기간 전체 데이터로 한계를 계산하고 해당 기간의 모든 측정값을 표시합니다. 기록 표는 50건씩 표시합니다. 기간·그룹 조회 조건은 세션 내에서 사용하며, 저장한 그룹 정의는 영구 저장됩니다.

## 첨부 엑셀

사용자가 제공한 `1.3 SPC 관리 대장_품질검사_공정검사, 저장탱크검사_2026년_수정본_최종.xlsx`의 첫 시트 원시 입력 영역에서 72,012건을 `public/workbook.json`으로 추출했습니다. 원본 파일은 수정하지 않았습니다. 대상 10개, 분석 항목 16개를 기본 목록으로 제공하고, 실제 기록은 화면의 **엑셀 측정값 불러오기**를 눌렀을 때 저장합니다. 반복 불러오기는 방지합니다. 수동 입력한 기록은 유지합니다.

빈칸·텍스트·오류 셀과 그래프용 집계 영역은 제외하며 숫자 0과 음수는 보존합니다. 날짜는 2026년 및 31칸씩 배치된 월·일 머리글에서 가져옵니다. 시각은 원본에 없으므로 생성하지 않고 당일 행 순번을 사용합니다. 원본 셀 주소를 기록합니다. 측정 기록의 행 순서가 실제 채취 순서를 의미하는지 확인 후 I-MR 결과를 해석하세요. 원본에 입력된 날짜를 그대로 유지하며 미래 날짜를 임의로 삭제하지 않습니다.

규격은 자동 확정하지 않습니다. 수분은 원본 ℃ 표기를 사용하고, 기타 가스 항목의 ppm 단위도 사용 전에 확인하세요. HALO3 미세수분은 원시값과 그래프 표기의 단위 변환이 명확하지 않아 단위를 공란으로 두었습니다. **항목 / 규격 설정**에서 올바른 단위·상한·하한을 확인해 입력하세요. 설정 변경은 모든 대상의 해당 항목 과거 판정에도 적용됩니다. 규격 이력별 판정은 제공하지 않습니다.

추출 재실행(개발용, Python 및 openpyxl 필요):

```sh
python scripts/extract_workbook.py '/path/to/source.xlsx' public/workbook.json
```

임의 형식의 엑셀 파일을 브라우저에서 업로드하는 기능은 포함하지 않습니다. 이번 첨부 파일에 맞춘 추출 자료를 제공합니다.

## 검증

```sh
npm test
```

통계 계산, 그룹·항목·날짜 필터, 첨부 데이터 참조 무결성, 백업 유효성 및 CSV 이스케이프를 검사합니다.

I 관리한계는 평균 ± 2.66 × MR 평균, MR 한계는 0과 3.267 × MR 평균입니다. σ는 MR 평균 / 1.128입니다. 양측 규격이면 Cpk를, 한쪽 규격이면 해당 측 지수를 표시합니다. 2개 미만 또는 분산이 0이면 공정능력을 표시하지 않습니다. 25개 미만은 참고용으로 표시합니다. 추세·연속점 등 추가 관리도 규칙은 판정하지 않습니다. 규격 이탈과 통계적 관리한계 이탈은 별도로 표시합니다.

## 저장과 운영 범위

전체 데이터는 해당 브라우저·사이트 주소의 IndexedDB에 저장됩니다. 이전 버전 localStorage 기록은 첫 실행 시 별도 대상·항목으로 이관하며 원본 저장값은 삭제하지 않습니다. 공유 DB, 로그인, 자동 서버 백업은 없습니다. 정기적으로 전체 JSON 백업을 내려받으세요. CSV는 조회 결과용이고 전체 복원에는 JSON을 사용합니다. 브라우저 데이터 삭제 또는 접속 주소 변경 시 기록이 자동 공유되지 않습니다. 서버 자체가 사용자 측정값을 수신하거나 저장하지 않습니다.

이 앱에는 인증이 없고 첨부 자료 JSON을 서버에서 제공하므로, 실제 운영에서 외부에 공개하기 전에 접근제어 및 공유 저장소를 별도로 구성해야 합니다. GitHub 저장소는 소스 파일 보관용입니다. 앱을 사용하려면 Node.js로 실행하거나 별도 웹 호스팅에 배포하세요.

## 미검출 (ND) 관리

항목 설정에서 규격 상한 또는 하한의 유형을 **미검출 (ND)**로 선택할 수 있습니다. 미검출 규격에서는 미검출 결과만 적합하며 숫자 0을 포함한 수치 결과는 규격 이탈로 판정합니다. 미검출 규격과 수치 규격은 동시에 지정할 수 없습니다. 수치 규격에서 미검출 결과는 검출한계(LOD) 정보가 없으므로 판정 불가로 표시합니다.

측정 입력의 결과 구분에서도 미검출을 선택할 수 있습니다. 미검출은 `result: "ND", value: null`로 저장하며 0으로 대체하지 않습니다. 평균·분산·Cpk 계산에서 제외하고, 미검출을 사이에 둔 두 숫자를 이동범위로 연결하지 않습니다. 개별값 관리도는 미검출 위치에서 선을 끊고 하단에 ND 표시를 합니다. CSV·전체 백업·복원에도 미검출 정보를 보존합니다. 이전 숫자 기록과 백업은 그대로 사용할 수 있으며, 기존 엑셀의 0을 임의로 미검출로 바꾸지 않습니다.

## 10회 연속 입력

입력 대상·분석 항목·측정 날짜를 선택한 뒤 표에 최대 10회 측정값과 비고를 입력하고 **입력한 측정값 일괄 저장**을 누릅니다. 1개만 입력해도 저장할 수 있으며, 빈 행은 저장하지 않습니다. 기존 당일 기록의 마지막 순번에 표의 행 순서를 더해 기록하므로 중간 빈 행이 있으면 순번에 공백이 생길 수 있습니다. Enter는 같은 열의 다음 행으로 이동하며 마지막 행에서는 저장 버튼으로 이동합니다.

측정값 칸은 숫자, `ND`, `미검출`을 지원합니다. 엑셀에서 복사한 세로 1열 또는 측정값·비고 2열을 원하는 시작 행에 붙여넣을 수 있습니다. 가로 3~10칸은 세로 입력 행으로 변환합니다. 가로 2칸은 측정값·비고로 해석하므로 두 측정값은 세로로 붙여넣으세요. 남은 입력 행보다 많은 값이나 잘못된 값은 붙여넣지 않으며 기존 입력 내용을 유지합니다. 저장 시에도 모든 행을 검증한 뒤 한 번의 저장 트랜잭션으로 추가합니다. 저장 실패 시 입력 내용은 유지하며 성공 시 표를 비웁니다. 아직 저장하지 않은 표 내용은 새로고침하면 사라집니다.

## 전체 분석 항목 관리도

산소·질소 등 등록된 모든 분석 항목의 개별값(I)·이동범위(MR) 관리도를 한 화면에 연속 표시합니다. 항목 바로가기를 누르면 해당 관리도로 이동합니다. 데이터가 없는 항목도 빈 상태로 표시합니다. 각 항목의 관리도에는 선택한 모든 라인이 표시되며 라인 그룹과 조회 기간은 전체 항목에 공통 적용됩니다. 단위가 다른 항목은 하나의 축에 혼합하지 않습니다.

상단 **기록·요약·규격 설정 항목** 선택은 기록 표·라인별 요약·CSV 및 규격 편집 대상을 바꾸며, 전체 항목 관리도를 숨기지 않습니다. 관리도 카드의 **이 항목 기록 / 규격 선택**으로 해당 항목을 선택할 수도 있습니다. **측정값 입력으로 이동** 바로가기로 10회 입력 표에 이동합니다. 관리한계는 항목·라인별 독립 계산이며, 선택 기간 전체 데이터로 계산한 한계와 해당 기간의 모든 측정값을 표시합니다. 기록 페이지 전환이나 단일 항목 선택 시 동일한 전체 관리도를 다시 그리지 않도록 하여 화면 갱신 부담을 줄였습니다.

## 조회 기간과 관리도

최근 300점 제한 없이 선택 기간의 모든 측정값을 표시합니다. 시작일·종료일을 포함하며, 기간 내 데이터가 없는 날짜도 실제 날짜 간격으로 유지합니다. 모든 항목의 I·MR 관리도에 같은 시작·종료일을 적용합니다. 날짜를 지정하지 않은 측은 해당 항목의 조회 데이터 범위로 표시합니다. 각 점의 설명에서 측정 날짜·당일 순번·값을 확인할 수 있습니다. 관리한계와 통계도 선택 기간의 데이터만으로 계산하며, MR의 첫 측정점은 기간 이전 값과 연결하지 않습니다.
